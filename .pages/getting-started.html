One-Command Installation • No Build Tools Required

Get CivQuest
Running in Minutes

Install the cq CLI, configure your inference endpoint, and launch autonomous settlers — all without cloning a repository or installing build toolchains.

Install Command

Run a single command to download and install the CivQuest CLI and dependencies.

bash — install CivQuest 
curl -fsSL https://raw.githubusercontent.com/btposey/civquest/main/install.sh | bash -s -- -y all

This downloads prebuilt binaries from GitHub Releases and installs them to ~/.local/bin. No Go compiler, Gradle, or repository clone is required.

To install a specific version, append -- --version 0.1.0 before the target:

bash — install specific version 
curl -fsSL https://raw.githubusercontent.com/btposey/civquest/main/install.sh | bash -s -- --version 0.1.0 -y all

System Requirements

What you need before running CivQuest.

🖥️

Hardware

RAM: Minimum 8 GB (4 GB for the Minecraft server, 2 GB for agent processes, remainder for LLM inference).
Disk: 10 GB for server runtime, mod JAR, and agent state databases.
CPU: x86_64 (amd64) or ARM64 (aarch64) Linux system.

☕

Java Runtime

Java 21 is required for the NeoForge Minecraft server. Install via your package manager or sudo apt install openjdk-21-jdk on Debian/Ubuntu systems.

🧠

LLM Inference Endpoint

Agents require a local or remote LLM gateway for dialogue, barter negotiation, and construction planning. Supported backends: Ollama (default) or vLLM. You must deploy and maintain your own inference server.

Inference Cost Disclaimer

Running LLM inference consumes compute resources and/or API tokens. All inference costs are borne by the user. CivQuest does not provide, manage, or subsidize any LLM inference service. If you use a cloud-based inference provider (e.g., OpenAI, Anthropic, Together AI), you are responsible for all associated API costs. Local inference via Ollama or vLLM requires GPU or CPU compute capacity.

Quick Start

From installation to your first autonomous settlers in five steps.

Step Command Description
1 cq status Verify your installation. Displays the XDG directory topology, binary paths, and runtime status.
2 cq gateway test Confirm your LLM inference endpoint is reachable. Tests connectivity to the configured Ollama/vLLM gateway.
3 cq server setup Download and configure the NeoForge dedicated server with the CivQuest mod pre-installed.
4 cq agent create aria Create your first agent profile. Starter agents (Aria the farmer, Boreas the builder) are pre-configured.
5 cq server start Launch the Minecraft server. Agents will spawn as autonomous settlers in your world.

To join the world as a player, install the Minecraft launcher profile:

bash — install client profile 
cq client install

Then select the "CivQuest" profile in the Minecraft launcher and join your server.

CLI Reference

Complete reference for the cq command-line interface, organized by domain.

Server Management

CommandDescription
cq server setupDownload NeoForge server runtime, stage the mod JAR, and write default configuration files.
cq server startStart the dedicated Minecraft server in the background.
cq server stopGracefully stop the running server.
cq server statusShow server process status, port binding, and uptime.
cq server logsStream live server logs (follow mode).
cq server export-recipesExport all registered crafting recipes to JSON for blueprint authoring.

Agent Management

CommandDescription
cq agent listList all configured agent profiles and their current states.
cq agent status <name>Show detailed status for a specific agent: position, health, inventory, and active goals.
cq agent create <name>Create a new agent profile with the specified name and default traits.
cq agent start <name>Start the isolated agent process and connect it to the server.
cq agent stop <name>Gracefully stop an agent process.
cq agent start-clan <clan>Start all agents belonging to a specific clan.
cq agent logs <name>Stream live logs from a specific agent process.

Inference Gateway

CommandDescription
cq gateway testTest connectivity to the configured LLM gateway (Ollama/vLLM) and verify model availability.
cq gateway evalRun a diagnostic evaluation: send a test prompt and measure latency, token count, and JSON schema compliance.

Client Configuration

CommandDescription
cq client installInstall the NeoForge client, stage the CivQuest mod, and create a "CivQuest" launcher profile.

Blueprints

CommandDescription
cq blueprint listList all available construction blueprints (official, player-imported, and LLM-generated).
cq blueprint validate <file>Validate a YAML blueprint file for structural correctness and Bill of Materials completeness.
cq blueprint generateUse the LLM gateway to generate a new blueprint from a natural language description.

Clans

CommandDescription
cq clan inspect <clan>Show clan membership, prestige score, granary stock, and diplomatic relationships.
cq clan prestige <clan>Display detailed prestige breakdown: completed structures, surviving agents, and chronicler entries.
cq clan diplomacy <clan>Show inter-clan diplomacy state: alliances, trade agreements, and hostilities.

General

CommandDescription
cq statusDisplay installation topology: XDG directory paths, binary versions, server status, and active agent count.
cq --helpShow available subcommands and global flags.

Configuration

CivQuest follows the XDG Base Directory specification. All paths are dynamically resolved.

Environment VariableDefaultPurpose
XDG_CONFIG_HOME~/.configAgent profiles, global.yaml, blueprints
XDG_DATA_HOME~/.local/shareServer runtime, agent databases, clan data, graveyard
XDG_STATE_HOME~/.local/stateLogs, PID files, UNIX domain sockets
INSTALL_BIN_DIR~/.local/binInstalled binaries (cq, civquest-agent)

The global configuration file at ~/.config/civquest/global.yaml controls LLM gateway settings, inference temperature, supervisor limits, and gRPC connectivity. Edit this file to point to your Ollama or vLLM endpoint.
