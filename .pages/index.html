Dual-Layer System Topology

Decoupling physical voxel simulation in the JVM from cognitive deliberation in Go.

⚡

Server-Side Mod Layer

Built on NeoForge 21.1+ (Java 21). Spawns server-side settler avatars with full player physics, delivers dynamic agent skin packets, streams 5 Hz sensory frustum telemetry, and delegates physical voxel pathfinding to an integrated Baritone API wrapper.

🧠

Two-Tier Cognitive Engine

System 1: Sub-5ms deterministic utility AI (0 LLM tokens) for combat panic, shield blocking, and hunger. System 2: Asynchronous JSON-validated LLM inference (Ollama/vLLM) for dialogue, haggling, Chronicler book writing, and quadrant layout.

🏛️

Process-Per-Agent Isolation

Each agent executes as an independent operating system process (civquest-agent) managed by the cq supervisor daemon. Every agent retains dedicated XDG directories, SQLite databases, and UNIX domain sockets for live inspection.

Civilization Mechanics

Emergent Dynasties, Spatial Construction, and High-Stakes Permadeath

🛡️

Permadeath & Graveyards

Agents never respawn. When an agent falls, their state directory is permanently moved to the cold graveyard archive alongside an epitaph and death certificate. Surviving spouses transition to widowed status, and Chroniclers document their sacrifice.

📐

Spatial Quadrant Building

Architects parse YAML blueprints, compute Bills of Materials against granary stock, and subdivide structures into 4 spatial quadrants (NW, NE, SW, SE). Builders place voxels bottom-up (Ymin → Ymax) to eliminate collisions and entrapment.

🌾

Dynasties & Sharecropping

Surplus granaries trigger the dynastic reproduction governor, blending parent traits with Gaussian mutation. Agrarian agents propose sharecropping agreements to human players, cultivating modded crops and depositing 50% yields directly into player chests.

Developer Quickstart

Set up the local development toolchain and inspect ready tasks in seconds.

bash — civquest setup 
# 1. Clone the repository
git clone https://github.com/btposey/civquest.git
cd civquest

# 2. Run the automated local toolchain setup (installs protoc, buf, sqlite-vec)
./setup.sh

# 3. View ready development tasks using Beads (bd)
bd ready
# Output: ○ cq-bu1.1: Define master Protobuf v3 contract and configure code generation

# 4. Claim work and start building
bd update cq-bu1.1 --claim
