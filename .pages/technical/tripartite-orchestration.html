Tripartite Neurological
Latency Hierarchy

Embodied agents operating in physics-driven environments face a fundamental biological dilemma: deliberative cognition takes seconds, but lethal threats arrive in milliseconds. CivQuest resolves this via a three-tier neurological latency partition separating in-engine spinal reflexes, tactical utility AI, and asynchronous strategic LLM inference.

Level 1: Intuitive Mental Model

Biological Analogies & The Latency Dilemma

TMLI-15 Framing

Consider what happens when your hand touches a glowing stovetop. You do not consciously deliberate, consult a mental dictionary, or evaluate your options. Your spinal cord triggers an involuntary muscle contraction that pulls your arm back before the pain signal has even arrived at your conscious brain. The conscious brain only realizes what happened hundreds of milliseconds later.

Living organisms survive dynamic, hostile worlds because their neurological control is split across distinct speed layers:

  • The Spinal Cord (Sub-Conscious Reflexes): Fires in <10 milliseconds. Protects the physical organism from catastrophic damage (flinching, blinking, catching balance) without waiting for brain approval.
  • The Basal Ganglia & Brainstem (Tactical Intuition): Cycles in 50–100 milliseconds. Governs continuous muscle coordination, rhythm, walking patterns, and instant fight-or-flight reactions.
  • The Prefrontal Cortex (Deliberative Cognition): Operates over seconds or minutes. Plans long-term goals, evaluates social relationships, reads books, and negotiates treaties.

If an AI agent forced every action through a Large Language Model, every skeleton arrow would hit the agent before the prompt even finished tokenizing. CivQuest mirrors biological neurological hierarchies by embedding sub-tick reflexes inside the game engine, tactical utility loops in Go, and strategic deliberation in asynchronous background workers.

Level 3: Deep As-Built Implementation

Concrete Contracts, Memory Invariants & Concurrency

TMLI-Pro Systems Engineering

1. In-Engine Java Peripheral Reflexes (`AgentEntity.java`)

Layer 1A executes directly inside Minecraft's dedicated server tick (`net.neoforged.neoforge.event.tick.ServerTickEvent`). At 20 Hz, each server tick provides an absolute budget of 50.0 ms across all entities. To prevent lag spikes, CivQuest's in-engine reflexes are hard-capped at 0.1 ms per agent.

Trajectory Intersection Algorithm: Every tick, `AgentEntity` checks for active projectile entities within a bounding sphere ($r = 12\text{ blocks}$). For each projectile $\vec{P}$ with velocity $\vec{V}$, it computes the closest point of approach ($t_{\text{cpa}}$) to the agent's bounding box:

t_{\text{cpa}} = -\frac{(\vec{P}_0 - \vec{A}) \cdot \vec{V}}{|\vec{V}|^2}, \quad \text{where } \vec{A} \text{ is agent position}

If $0 < t_{\text{cpa}} < 0.5\text{s}$ and the impact distance is within the agent's hitbox radius, the avatar automatically raises its offhand shield (`startUsingItem(InteractionHand.OFF_HAND)`) and appends a `ReflexNotice` into the outgoing telemetry buffer.

2. Ascending Afferent Telemetry (`ReflexNotice`)

In biology, afferent nerves carry sensory signals from peripheral receptors upward to the central nervous system. CivQuest implements this via `ReflexNotice` messages inside the Protobuf `TelemetryFrame`:

proto/civquest/v1/civquest.proto 
message ReflexNotice {
  enum ReflexType {
    REFLEX_TYPE_UNSPECIFIED = 0;
    REFLEX_TYPE_SHIELD_RAISED = 1;
    REFLEX_TYPE_OBSTACLE_STEP = 2;
    REFLEX_TYPE_ITEM_VACUUMED = 3;
    REFLEX_TYPE_FIRE_EXTINGUISHED = 4;
  }
  ReflexType type = 1;
  int64 tick = 2;
  int32 source_entity_id = 3;
  string details = 4;
}

3. Go Tactical Utility Loop (`internal/system1/evaluator.go`)

The external Go worker process runs at 5 Hz (every 200ms). When a `TelemetryFrame` is received containing a `ReflexNotice`, the utility evaluator immediately penalizes the agent's survival confidence score without waiting for higher-level timers. The confidence formula is defined as:

C = \left( \frac{\text{Health}}{\text{MaxHealth}} \times 0.4 \right) + \left( M_{\text{gear}} \times 0.4 \right) - \left( N_{\text{threats}} \times 0.15 \right) - P_{\text{reflex}}

Where $P_{\text{reflex}} = 0.25$ if a `REFLEX_TYPE_SHIELD_RAISED` notice was ingested within the last 1.0 second. If $C < 0.40$, the Hierarchical FSM immediately triggers a transition to `EMERGENCY` state, issuing an immediate reverse vector `NavigateIntent` to escape danger.
