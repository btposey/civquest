Architecture Invariant Dual-System Partitioning Sub-Tick Survival Afferent Loops

Tripartite Neurological
Latency Hierarchy

Embodied agents operating in physics-driven environments face a fundamental biological dilemma: deliberative cognition takes seconds, but lethal threats arrive in milliseconds. CivQuest resolves this via a three-tier neurological latency partition: System 1[1] is split between peripheral in-engine reflexes (Layer 1: Peripheral Reflex Arc) and central procedural routines (Layer 2: Procedural Execution), while System 2 handles central deliberative language model inference (Layer 3: Executive Deliberation).

The Neurological Dilemma in Embodied Simulation

Consider what happens when your hand touches a glowing stovetop. You do not consciously deliberate, consult a mental dictionary, or evaluate your options. Your spinal cord triggers an involuntary muscle contraction that pulls your arm back before the pain signal has even arrived at your conscious brain. The conscious brain only realizes what happened hundreds of milliseconds later.

Living organisms survive dynamic, hostile worlds because their neurological control is split across distinct speed layers:

  • Layer 1 — The Spinal Reflex Arc (Involuntary Periphery):[2] Fires in <10 milliseconds. Protects the physical organism from catastrophic damage (flinching, blinking, raising a shield, catching balance) without waiting for brain approval.
  • Layer 2 — The Subcortical Procedural Engine (Procedural Execution & Muscle Memory):[3] Cycles in 50–200 milliseconds. Governs continuous motor coordination, terrain navigation, habitual state transitions, and immediate fight-or-flight reactions.
  • Layer 3 — The Prefrontal Executive Cortex (Deliberative Cognition):[4] Operates over seconds or minutes. Plans long-term goals, evaluates social relationships, negotiates barter terms, and drafts architectural blueprints.

If an AI agent forced every action through a Large Language Model, every skeleton arrow would hit the agent before the prompt even finished tokenizing. CivQuest mirrors biological neurological hierarchies by embedding sub-tick reflexes inside the game engine, tactical utility loops in Go, and strategic deliberation in asynchronous background workers.

Three-Tier Latency Architecture & Execution Boundaries

Physical voxel survival demands sub-tick (<50ms) reaction times to evade kinetic hazards, while LLM inference operates on multi-second timelines (500ms to 4000ms). To satisfy both constraints simultaneously, CivQuest establishes strict execution and isolation boundaries between tiers.

Architectural Boundary Invariants

Layer 1 (System 1 Periphery — Peripheral Reflex Arc / Java): Hard ceiling of <0.1 ms per agent per server tick. Runs synchronously inside the 20 Hz tick loop with zero network IPC and zero heap allocation.

Layer 2 (System 1 Center — Procedural Execution / Go): Synchronous <5.0 ms execution loop with zero LLM token consumption. Evaluates threat matrices, executes the Hierarchical FSM, and streams kinetic intents at 5 Hz.

Layer 3 (System 2 Center — Executive Deliberation / LLM): Asynchronous background inference gateway. Generates dialogue, trade terms, and construction plans over multi-second windows without delaying reactive reflexes or kinetic movement.

Deterministic Survival Guarantee

Zero-token survival reflexes in Layers 1 and 2 guarantee that agents never perish due to network latency, gRPC backpressure, or LLM token generation delays while preserving rich Layer 3 dynastic behaviors.

As-Built Subsystem Contracts & Data Flow

1. In-Engine Java Peripheral Reflexes: Layer 1 (AgentEntity.java)

Layer 1 operates as System 1 at the periphery, executing directly inside Minecraft's dedicated server tick (ServerTickEvent). At 20 Hz, each server tick provides an absolute budget of 50.0 ms across all entities. To prevent lag spikes, CivQuest's in-engine reflexes are hard-capped at 0.1 ms per agent.

Trajectory Intersection Algorithm: Every tick, AgentEntity scans active projectile entities within a bounding sphere (radius $r = 12\text{ blocks}$). For each projectile $\vec{P}$ with velocity $\vec{V}$, it computes the closest point of approach ($t_{\text{cpa}}$) to the agent's bounding box:

t_cpa = -((P_0 - A) · V) / |V|²

If $0 < t_{\text{cpa}} < 0.5\text{s}$ and the impact distance is within the agent's hitbox radius, the avatar automatically raises its offhand shield (startUsingItem(InteractionHand.OFF_HAND)) and appends a ReflexNotice into the outgoing telemetry buffer.

2. Ascending Afferent Telemetry (ReflexNotice)

In biology, afferent nerves carry sensory signals from peripheral receptors upward to the central nervous system. CivQuest implements this via typed ReflexNotice messages inside the Protobuf TelemetryFrame:

message ReflexNotice { enum ReflexType { REFLEX_TYPE_UNSPECIFIED = 0; REFLEX_TYPE_SHIELD_RAISED = 1; REFLEX_TYPE_OBSTACLE_STEP = 2; REFLEX_TYPE_ITEM_VACUUMED = 3; REFLEX_TYPE_FIRE_EXTINGUISHED = 4; } ReflexType type = 1; int64 tick = 2; int32 source_entity_id = 3; string details = 4; }

3. Go Procedural Execution Loop: Layer 2 (internal/system1/evaluator.go)

Layer 2 functions as System 1 at the center, executing within the dedicated Go worker process at 5 Hz (every 200 ms). When a TelemetryFrame is received containing a ReflexNotice, the procedural utility evaluator immediately penalizes the agent's survival confidence score without waiting for higher-level timers:

Confidence = (Health / MaxHealth * 0.4) + (GearScore * 0.4) - (ThreatCount * 0.15) - ReflexPenalty

Where ReflexPenalty = 0.25 if a REFLEX_TYPE_SHIELD_RAISED notice was ingested within the last 1.0 second. If Confidence < 0.40, the Hierarchical FSM immediately triggers a transition to EMERGENCY state, issuing an immediate reverse vector NavigateIntent to escape danger.

4. Deliberative Executive Inference: Layer 3 (internal/system2/gateway.go)

Layer 3 acts as System 2 at the center, operating completely asynchronously via HTTP REST to local Ollama or vLLM inference gateways. It evaluates long-horizon decisions—dialogue synthesis, barter value negotiation, architectural quadrant planning, and chronicler diary entries. Because Layer 3 runs out-of-band with strict JSON Schema constraints, multi-second token generation latencies never stall Layer 1 peripheral defenses or Layer 2 procedural motor execution.

Footnotes & Conceptual Provenance
  1. Dual-Process Cognitive Theory (System 1 vs. System 2): Originating in cognitive psychology and decision research, dual-process theory distinguishes fast, autonomous, context-triggered procedural operations (System 1 / Type 1) from slow, deliberative, resource-intensive conscious reflection (System 2 / Type 2). In CivQuest, System 1 is physically partitioned across in-engine peripheral reflexes (Layer 1) and out-of-process procedural state routines (Layer 2), while System 2 operates as centralized LLM inference (Layer 3). See: Kahneman, D. (2011). Thinking, Fast and Slow; Evans, J. S. B., & Stanovich, K. E. (2013). Dual-process theories of higher cognition: Advancing the debate. Perspectives on Psychological Science, 8(3), 223–241. ↩
  2. Peripheral Somatic Reflex Arc: In vertebrate neurobiology, monosynaptic and polysynaptic spinal reflex arcs process afferent sensory input directly at the spinal cord interneuron level, bypassing the brainstem and cerebral cortex to trigger immediate efferent motor output (e.g., nociceptive withdrawal or protective blinking) in <10 ms to prevent fatal tissue trauma. See: Sherrington, C. S. (1906). The Integrative Action of the Nervous System. Yale University Press. ↩
  3. Subcortical Action Selection & Procedural Memory: The basal ganglia and cerebellum coordinate automated motor sequences, habit execution, and winner-take-all behavioral selection without imposing load on conscious prefrontal working memory. The striatal feedback loop evaluates competing sensory affordances and gates the execution of automated movement programs. See: Redgrave, P., Prescott, T. J., & Gurney, K. (1999). The basal ganglia: a vertebrate solution to the selection problem? Neuroscience, 89(4), 1009–1023; Doya, K. (2000). Complementary roles of basal ganglia, cerebellum and cerebral cortex in learning. Neuroscience Research, 38(1), 11–23. ↩
  4. Prefrontal Executive Function & Cognitive Control: The prefrontal cortex governs top-down goal representation, symbolic reasoning, linguistic discourse, and counterfactual planning over multi-second to multi-minute horizons, operating under strict working memory capacity limits. See: Miller, E. K., & Cohen, J. D. (2001). An integrative theory of prefrontal cortex function. Annual Review of Neuroscience, 24(1), 167–202. ↩
