Deliberative Inference &
Context Assembly Pipelines

While System 1 guarantees physical survival, System 2 drives high-level cognitive life: social barter negotiation, dynastic book chronicles, settlement landmark naming, and spatial architectural blueprints. CivQuest connects to local LLM gateways via strict JSON Schema boundaries and dual-temperature sampling.

Constrained Deliberation & Dual-Temperature Sampling

Imagine directing an improvisational theatre actor. If you give them complete freedom with no guardrails, they might hallucinate alien spaceships in the middle of a medieval historical play. If you instead hand them an exact template with specific slots—such as "Trade Proposal: Offer X items for Y items"—they can express creative personality without breaking the rules of the world.

Furthermore, different cognitive tasks require different levels of randomness:

  • Structured Tactical Decisions (Low Temperature $\tau = 0.2$): When calculating barter exchange ratios or assembling construction blueprints, we need deterministic, mathematical consistency. Zero hallucinations are tolerated.
  • Narrative Lore & Social Dialogue (High Temperature $\tau = 0.8$): When settlers sit around an evening campfire writing chronicles in Minecraft books or chatting with players, we want rich literary vocabulary, humor, and unique dynastic personalities.

CivQuest enforces this separation by routing structured outputs through strict JSON Schema parsers before any action touches the game engine.

Schema-Validated Inference Architecture & Token Budgeting

The System 2 inference pipeline connects to local endpoints (Ollama or vLLM) in asynchronous background goroutines. Context windows are partitioned into strict token budgets to prevent unbounded GPU latency.

Context Window & Schema Invariants

Context Budget Ceiling: Total prompt context must never exceed 4,096 tokens, split between persona (512 t), sensory snapshot (768 t), vector RAG (1,536 t), and task trigger (1,276 t).

Schema Enforcement: All structured LLM responses must strictly validate against Go struct JSON tags. Malformed responses trigger an automatic retry budget (max 2) before falling back to deterministic System 1 tables.

Hallucination Defense Guarantee

By enforcing Go JSON unmarshaling and type validation on all structured actions, malformed commands are rejected before touching game state, ensuring zero server crashes from invalid voxel coordinates or item IDs.

3. Failure Modes & Circuit Breakers

Executive deliberation runs entirely within non-blocking background routines. If the local inference engine experiences compute saturation or fails to respond within bounded deadlines, the following circuit-breaker sequence triggers:

  1. The pending request context cancels via timeout propagation.
  2. The procedural utility engine falls back to deterministic item-value lookup tables.
  3. The agent resolves the interaction immediately without stalling movement or starving sensory telemetry.
